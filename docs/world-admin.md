# Редактор мира

Мир хранится в `shared/world/hub.json`. Сервер проверяет его структуру, передаёт клиентам и использует те же скорости и координаты целей для серверных проверок. Секреты и настройки подключения к серверу в этот файл не входят.

## Доступ

Сначала зарегистрируйте пользователя обычным способом. В терминале WSL на компьютере сервера:

```bash
cd /home/despy/projects/Sail_Academy/server
DEBUG=false .venv/bin/python admin.py grant ИМЯ_ПОЛЬЗОВАТЕЛЯ
```

Список администраторов: `DEBUG=false .venv/bin/python admin.py list`. Отозвать права: `DEBUG=false .venv/bin/python admin.py revoke ИМЯ_ПОЛЬЗОВАТЕЛЯ`. Пользователь должен уже существовать; привилегия привязана к ID аккаунта. Файл `server/data/admins.json` хранится только на сервере. Без записи в нём доступ запрещён; регистрацию администратором с клиента включить нельзя.

После входа администратор увидит кнопку **«Админ-панель»**; её также можно открыть на `/admin.html` и авторизоваться. Если права выданы во время игры, выйдите и войдите снова. Нажмите Esc, чтобы освободить курсор перед нажатием кнопки.

## Черновик и публикация

Поля меняют скорость, камеру и атмосферу; в списке можно выбрать объект, NPC, цилиндр или GLB-декорацию и задать координаты и размеры. В разделе JSON доступны остальные параметры, включая состав объектов, материалы, подписи и станции заданий. Координаты NPC и станций используются также на сервере; если перемещаете окружение, связанные объекты и станции нужно переместить согласованно. Для добавления или удаления элементов используйте JSON.

Предпросмотр черновика обновляется после проверки и не влияет на игроков или файл мира. **«Сохранить мир»** публикует изменения; клиенты в хабе проверяют обновления примерно раз в три секунды, сохраняя позицию и вид камеры. Открытый диалог завершается без принудительного закрытия, и обновление применяется после него. **«Отменить изменения»** возвращает черновик к последней загруженной версии. Если другой администратор успел сохранить мир, сервер отклонит устаревший черновик: сохраните его отдельно и перезагрузите страницу перед повторным редактированием.

Перед каждым изменением опубликованной версии создаётся копия в `shared/world/backups/`. Список копий доступен в панели: можно открыть копию в черновике или явно откатить опубликованную версию. При откате текущий мир также сохраняется в резервную копию. Копии намеренно не удаляются автоматически; создавайте внешние резервные копии папки при переносе проекта.

Файл проверяется при публикации: скорости, границы камеры, типы объектов, координаты, цвета, идентификаторы наставников и путь к локальным GLB. Не меняйте файл вручную во время сохранения из панели: защита от конфликтов рассчитана на обращения через API. Если JSON повреждён вручную, восстановите валидную копию из `shared/world/backups/` до запуска сервера.
