# Учебные материалы

Файлы в пяти каталогах категорий индексируются командой `python -m app.ai.indexer`.
Поддерживаются UTF-8 `.txt` и `.md`; абзацы разделяют фрагменты. Существующие
файлы воспроизводят проверенные факты из `app/ai/content.py`, без удаления оригинала.
Добавляйте только проверенные материалы, указывайте происхождение и повторно
запускайте индексатор. Пользовательская переписка в этот каталог не попадает.
