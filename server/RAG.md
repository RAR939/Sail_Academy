# Локальный RAG для наставников

Из каталога `server` установите зависимости (`python -m pip install -e '.[dev]'`,
либо `uv sync --group dev` при использовании uv). Создайте `.env` по образцу
`.env.example`, задав собственный `JWT_SECRET`. Существующий `.env` может
переопределять модель; проверьте в нём `OLLAMA_MODEL=qwen3:4b-instruct`.

Запустите Ollama и установите модели:

```bash
ollama pull qwen3:4b-instruct
ollama pull nomic-embed-text
curl http://127.0.0.1:11434/api/tags
python -m app.ai.indexer
python start.py
```

Если в окружении задано `DEBUG=release` или другое не-булево значение,
запускайте команды сервера с префиксом `DEBUG=false`.

Индексация читает `knowledge/`, разбивает текст на абзацы/предложения и хранит
эмбеддинги и ссылки на источники в отдельной SQLite `rag_index.sqlite3`. Изменённые
файлы и смена модели эмбеддингов запускают переиндексацию; удалённые файлы
удаляются из индекса. Запрос вычисляет один вектор, выбирает до `RAG_TOP_K`
фрагментов по косинусному сходству с небольшим приоритетом специализации NPC,
после чего передаёт их в `/api/chat`. В ответе API `rag.sources` содержит ID,
файл, категорию и оценку. Память игрока остаётся отдельно в `NPCMemory`.
Ошибка моделей возвращает HTTP 503 без изменения памяти и прогресса. Для
отключения поиска предусмотрен `RAG_ENABLED=false`; это не включает fallback.

`RAG_MIN_SIMILARITY=0.73` — предварительный порог, подобранный на нескольких
вопросах текущего корпуса, а не гарантия достоверности. Для nomic используются
префиксы `search_document:` и `search_query:`; смена этого формата автоматически
вызывает переиндексацию. Результаты заметно ниже лучшего сходства отбрасываются.
Для калибровки запустите реальную проверку ниже и соберите набор тематических,
переформулированных и посторонних вопросов. Сравните оценки релевантных и
нерелевантных результатов, настройте порог по нужному компромиссу полноты и
точности и повторите проверку. При отсутствии материалов модель получает явное
указание признать нехватку сведений; автоматическая проверка достоверности всех
её утверждений не гарантируется.

```bash
python -m pytest tests -q
RUN_OLLAMA_INTEGRATION=1 python -m pytest tests/test_rag.py -q
```

Интеграционный тест требует работающей Ollama, обеих моделей и предварительной
индексации. Время эмбеддинга, поиска и генерации выводится в журнал сервера;
скорость зависит от оборудования. Индекс содержит только проверенный небольшой
корпус, поэтому многие вопросы останутся без достаточного источника.
