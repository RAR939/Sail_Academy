# ППГ 2025–2028: поиск по загруженному PDF

В сборку включён файл `sail_ai/resources/PPG_2025_2028.pdf` (154 страницы). После установки зависимостей и запуска API доступен поиск по тексту PDF. PDF обрабатывается локально, не отправляется в Groq.

Авторизованный пользователь может вызывать:
- `POST /ai/rules/search` с JSON `{"text":"правило 10 противоположные галсы"}` — страницы и выдержки.
- `POST /ai/rules/ask` с JSON `{"npcId":"morozov","text":"Что говорит правило 10?"}` — объяснение-навигация по PDF с указанием страниц.
- `POST /ai/dialog` или `/ai/ask` с тем же `npcId` и явным упоминанием ППГ или номера правила — маршрутизируется в PDF-поиск.
- WebSocket `/ws/ai` также поддерживает запросы с явным номером правила.

**Ограничения:** текст PDF содержит редакторские правки и зачёркивания, которые при машинном извлечении теряют форматирование. Поэтому сервис **не делает автоматических юридически/спортивно обязательных выводов** по найденным фрагментам, а предоставляет цитаты-ориентиры и страницы. Для окончательного ответа надо проверять страницу в оригинальном PDF, а также применимость правил класса, гоночной инструкции и возможных изменений.

Поиск лексический (BM25), не гарантирует правильную интерпретацию сложного случая. Он не заменяет судейство. Если нужно, можно добавить отдельный редакторский индекс проверенных положений без зачёркнутого текста.
